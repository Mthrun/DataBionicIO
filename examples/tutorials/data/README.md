# Tutorial inputs

These files are fixed inputs for the DataBionicIO tutorials.
The [source page](../../../docs/reference/sources.md) gives attribution and data provenance.
The [manifest](manifest.json) records SHA-256 digests and file sizes.

The Hepta files have the same bytes as the publication fixtures in the repository.
The study preparation program supplied their keys and names.
The hydrology file has the same bytes as the copy in Supplementary Data S2.
The source data is in Zenodo record 4498241.

The four Firebrowse annotation files have the same bytes as the source files in Zenodo record 21849070.
Michael Thrun and Julian Märte made that deposit.
Its metadata gives the license as [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
These inputs do not include the full expression matrix.

The flow-cytometry file has its [download procedure](../../../docs/tutorials/flow-cytometry.md#get-the-input).
Dataset terms and the DataBionicIO software license are different.
